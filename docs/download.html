Install

The whole world, on your desktop.

Version 2.5.0
🪟

Windows

Windows 10 or 11

Download for Windows

Setup program (.exe)

Windows may show a SmartScreen warning when you run it: here is why.

Run it and choose Install. It installs for your account only, so Windows never asks for administrator rights. To remove it, uninstall from Settings, then Apps.

🍎

macOS

Macs with Apple silicon

Download for macOS

Disk image (.dmg)

Signed and notarised by Apple, so it opens like any other app.

Open the disk image and drag EarthNow to Applications.

🐧

Linux

Any distribution with Flatpak

Download for Linux

Flatpak bundle (.flatpak)

Tested on the latest Ubuntu LTS.

Install it with flatpak install --user earthnow.flatpak; Flatpak fetches what it needs from Flathub by itself.
